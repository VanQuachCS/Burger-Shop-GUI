- Developed a Java Swing GUI for a self-service burger ordering application, enabling users to add funds, select
menu items, specify quantities, place orders, and view account information.
- Implemented event-driven user interactions utilizing ActionListener callbacks across buttons, text fields, a combo
box, and a text area.
- Integrated the GUI with a provided back-end API to retrieve menu data, process user requests, display account
balances, and present order history.
